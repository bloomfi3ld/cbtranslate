# CBTranslate - Alternativa Libre a qTranslate

Debido a que la popular extensión **qTranslate** dejó de funcionar recientemente, muchas modelos se quedaron sin una herramienta esencial para traducir sus chats en tiempo real. **CBTranslate** nace como una alternativa directa, de código abierto y totalmente gratuita para solucionar este problema.

Este script funciona directamente en las plataformas de streaming (como Chaturbate y Stripchat), permitiendo la traducción instantánea de mensajes entrantes y salientes.

## 🚀 Cómo instalarlo

Sigue estos sencillos pasos para instalar y empezar a usar el script:

### 1. Instalar Tampermonkey
Primero, necesitas instalar un gestor de secuencias de comandos de usuario (userscripts). La mejor opción es **Tampermonkey**.
- 📥 **[Descargar Tampermonkey desde la Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)**
- Entra al enlace, haz clic en **"Añadir a Chrome"** y acepta la instalación.

### 2. Activar permisos de secuencias de usuario
Una vez instalado Tampermonkey, dependiendo de la configuración de tu navegador Chrome, es posible que debas asegurarte de tener activos los permisos para inyectar scripts. Puedes hacerlo haciendo clic en el icono de Tampermonkey en la barra de extensiones y asegurándote de que está **Habilitado**. (Si Chrome te solicita activar el *Modo de desarrollador* para las extensiones, hazlo desde `chrome://extensions/`).

### 3. Instalar CBTranslate
Con Tampermonkey activo, simplemente haz clic en el siguiente enlace. Se abrirá una pestaña de Tampermonkey donde solo tendrás que darle al botón de **Instalar**.

🔗 **[Haz clic aquí para instalar CBTranslate](https://raw.githubusercontent.com/bloomfi3ld/cbtranslate/master/cbtranslate.user.js)**
