

# CBTranslate - Alternativa Libre a qTranslate para web para adultos / Free Open Source Alternative to qTranslate for adult websites

  

Debido a que la popular extensión **qTranslate** dejó de funcionar recientemente, muchas modelos se quedaron sin una herramienta esencial para traducir sus chats en tiempo real. **CBTranslate** nace como una alternativa directa, de código abierto y totalmente gratuita a qTranslate, diseñada específicamente para sitios web para adultos y plataformas de webcams.

*Because the popular **qTranslate** extension recently stopped working, many models were left without an essential tool to translate their chats in real-time. **CBTranslate** was created as a direct, open-source, and completely free alternative to qTranslate, designed specifically for adult websites and webcam platforms.*

  

Este script funciona directamente en las plataformas de streaming, permitiendo la traducción instantánea de mensajes entrantes y salientes.

*This script works directly on streaming platforms, allowing instant translation of incoming and outgoing messages.*

Sigue estos sencillos pasos para instalar y empezar a usar el script:

*Follow these simple steps to install and start using the script:*

  

### 1. Instalar Tampermonkey / Install Tampermonkey

Primero, necesitas instalar un gestor de secuencias de comandos de usuario (userscripts). La mejor opción es **Tampermonkey**.

*First, you need to install a userscript manager. The best option is **Tampermonkey**.*

- 📥 **[Descargar Tampermonkey desde la Chrome Web Store / Download Tampermonkey from the Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)**

- Entra al enlace, haz clic en **"Añadir a Chrome"** y acepta la instalación.

-  *Click on the link, click on **"Add to Chrome"**, and accept the installation.*

### 2. Activar permisos de secuencias de usuario / Enable userscript permissions

Una vez instalado Tampermonkey, dependiendo de la configuración de tu navegador Chrome, es posible que debas asegurarte de tener activos los permisos para inyectar scripts. Puedes hacerlo haciendo clic en el icono de Tampermonkey en la barra de extensiones y asegurándote de que está **Habilitado**. (Si Chrome te solicita activar el *Modo de desarrollador* para las extensiones, hazlo desde `chrome://extensions/`).

*Once Tampermonkey is installed, depending on your Chrome browser settings, you may need to ensure you have the correct permissions enabled to inject scripts. You can do this by clicking the Tampermonkey icon in the extensions bar and making sure it is **Enabled**. (If Chrome asks you to enable *Developer Mode* for extensions, you can do it from `chrome://extensions/`).*
